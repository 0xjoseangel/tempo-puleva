# Logo oficial de Puleva

Coloca aquí el archivo oficial (del kit de marca del hackathon o de Lactalis Puleva):

- `puleva-logo.svg` (preferido) o `puleva-logo.png` (fondo transparente, ≥ 800 px de ancho)

La web lo detecta sola: lo usa en la etiqueta 3D de cada envase (en un sello blanco
"by + logo") y en todos los elementos `.wordmark` de la página. Si no hay archivo,
se muestra el wordmark de texto "by Puleva".
